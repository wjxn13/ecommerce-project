# 电商用户行为分析项目 (E-commerce User Behavior Analysis)

## 项目概览
构建端到端的数据分析流程：从模拟数据库日志提取、Python清洗分群、Excel透视表计算，到 Tableau 可视化看板，完整还原电商用户行为分析场景。

## 技术栈
- **数据库**：SQLite，使用 SQL 提取 DAU、转化漏斗、留存矩阵等核心指标
- **Python**：Pandas 数据清洗，规则引擎实现用户价值分群（高价值/犹豫/低活等）
- **Excel**：数据透视表计算转化率、留存率，条件格式热力图
- **Tableau**：搭建可交互看板，展示用户旅程与核心业绩

## 文件结构
- `notebooks/`：Jupyter Notebook 全流程代码（数据生成、SQL分析、清洗分群、留存计算）
- `data/`：模拟生成的用户数据（1000用户，8.7万条事件）及分析结果CSV
- `tableau/`：Tableau 工作簿（看板文件）
- `images/`：看板截图（DAU趋势、漏斗、留存热力图、分群对比）

## 关键产出
- **DAU趋势**：识别活跃用户波动规律
- **转化漏斗**：定位“浏览→加购”环节为最大流失点（转化率仅约30%）
- **留存热力图**：展示不同周队列的留存衰减，首周留存约55%，第三周降至25%
- **用户分群**：高价值客户占12%，贡献了45%的支付总额

## 快速查看
1. 核心分析逻辑见 `notebooks/ecommerce_user_behavior_analysis.ipynb`
2. 看板截图在 `images/` 文件夹中
3. Tableau 看板文件可下载后本地打开（需安装 Tableau Desktop 或 Tableau Public）

## 项目亮点
- 全流程覆盖（ETL → 特征工程 → 业务指标 → 可视化报告）
